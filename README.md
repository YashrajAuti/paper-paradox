## 📌 About
Paper Paradox is a secure digital academic verification system that replaces traditional paper-based processes using cloud computing and cryptographic hashing.

---

## ⚙️ Tech Stack
- HTML, CSS, JavaScript  
- Python (Flask)  
- Cloud Storage  
- Cryptographic Hashing  

---

## 🚀 Features
- 🔐 Secure document verification  
- ☁️ Cloud-based storage system  
- 🧾 Role-based authentication  
- ⚡ Real-time tracking  
- 📄 Paperless workflow
